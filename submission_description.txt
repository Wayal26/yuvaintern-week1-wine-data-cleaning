For Week 2 of the YuvaIntern Virtual Data Science with Python Trainee program, I performed an Exploratory Data Analysis (EDA) and visualization study on the Wine Recognition dataset. The dataset contains 178 wine samples, 13 numerical chemical features, and three target classes. I used Python with Pandas, Matplotlib, and scikit-learn to inspect the dataset and identify meaningful patterns.

The analysis began with a structural and data-quality inspection. I checked the number of observations and variables, data types, missing values, and duplicate records. No missing cells or duplicate rows were found. I then calculated descriptive statistics including mean, standard deviation, minimum, maximum, and quartile values to understand the scale and variation of each numerical feature.

I examined the target class distribution and found that the three wine classes do not have exactly equal sample counts. I also studied individual feature distributions using histograms, focusing on variables such as alcohol and malic acid. These plots showed that different chemical features have different distributions and levels of variation.

To understand class differences, I created boxplots for alcohol and flavanoids grouped by wine class. The visualizations showed that these features have useful differences across classes, with flavanoids providing particularly informative separation. I also generated a correlation heatmap to identify strong relationships between numerical variables. Several feature pairs showed substantial correlations, suggesting that some measurements may contain overlapping information.

Finally, I created a scatter plot of alcohol versus flavanoids and interpreted the class-dependent structure. Overall, the EDA provided useful insights into feature distributions, class differences, correlations, and potential modeling considerations. The complete notebook, Python source code, dataset, figures, and report are included in the GitHub project. This task improved my practical understanding of exploratory analysis, statistical summaries, visualization, interpretation of patterns, and preparing insights for future machine-learning work.
