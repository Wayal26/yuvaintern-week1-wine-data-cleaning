For Week 3 of the YuvaIntern Virtual Data Science with Python Trainee program, I performed an unsupervised learning and clustering analysis on the Wine Recognition dataset. The dataset contains 178 observations, 13 numerical chemical features, and three known wine classes. The main goal was to discover meaningful groups in the data without using the target labels during the clustering process.

I first prepared the numerical features for clustering. Because K-Means is based on distance calculations, I used StandardScaler to standardize the 13 features so that variables with larger numerical ranges would not dominate the clustering process. I then evaluated several possible numbers of clusters, from k=2 through k=10, using both the elbow method and silhouette scores. Inertia was used to study how within-cluster variation changes as the number of clusters increases, while the silhouette score was used to assess the quality and separation of the resulting clusters.

For the final analysis, I selected a three-cluster K-Means model because the dataset contains three known wine groups and the three-cluster solution provides an interpretable segmentation. The model used a fixed random state and multiple initializations for reproducibility and stability. I calculated the final silhouette score and examined the size of each cluster.

To visualize the high-dimensional clustering result, I applied Principal Component Analysis (PCA) to project the standardized data into two dimensions. I also created cluster-size charts and feature-profile visualizations to understand the chemical characteristics of each group. As an additional post-analysis check, I compared the discovered clusters with the original class labels using a contingency visualization and adjusted Rand index. These labels were not used to train the clustering model.

Overall, this task improved my practical understanding of unsupervised learning, K-Means clustering, feature standardization, cluster evaluation, PCA visualization, and interpretation of cluster characteristics. The complete Python code, notebook, dataset, figures, and report are included in the GitHub project.
