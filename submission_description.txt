For Week 4 of the YuvaIntern Virtual Data Science with Python Trainee program, I implemented a supervised machine-learning workflow for multiclass classification using the Wine Recognition dataset. The dataset contains 178 observations, 13 numerical chemical features, and three known wine classes. The objective was to use the chemical measurements to build predictive models and evaluate their performance using appropriate validation techniques and metrics.

I began by separating the input features from the target class and creating a stratified 80/20 train-test split with a fixed random state for reproducibility. Stratification was used to preserve the proportion of the three classes in both the training and testing data. For Logistic Regression, I used a scikit-learn Pipeline containing StandardScaler and LogisticRegression. Placing the scaler inside the pipeline helps prevent data leakage because scaling parameters are learned from the appropriate training data. I also implemented a Random Forest classifier as a nonlinear model that can capture feature interactions without requiring feature scaling.

Both models were evaluated using test accuracy, weighted precision, weighted recall, and weighted F1-score. In addition, I performed five-fold stratified cross-validation on the training set to examine the stability of the models rather than relying only on one test split. Confusion matrices were generated to inspect class-level prediction errors. I also created a model-performance comparison chart and a Random Forest feature-importance visualization.

The analysis demonstrated a complete supervised-learning process from data preparation through model training, validation, evaluation, and interpretation. The comparison between Logistic Regression and Random Forest helped me understand the differences between an interpretable linear baseline and a nonlinear ensemble method. The project also highlighted the importance of avoiding data leakage, selecting suitable evaluation metrics, and using cross-validation for more reliable performance assessment.

The complete Python source code, Jupyter notebook, dataset, evaluation results, visualizations, and DOCX report are included in the GitHub project.
