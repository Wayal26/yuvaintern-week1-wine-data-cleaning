I completed Week 1 of the YuvaIntern Virtual Data Science with Python Trainee internship by performing a complete data acquisition, cleaning, and preprocessing workflow in Python. I selected the UCI Wine Recognition dataset because it is a reliable, publicly available dataset with documented variables and a clear classification target.

The project begins by loading the dataset with Python and inspecting its dimensions, data types, descriptive statistics, missing values, and duplicate records. I also performed a basic domain validation of the numeric chemical measurements. The analysis showed that the dataset did not require missing-value imputation or duplicate removal. I then applied the interquartile range (IQR) method to identify statistical outliers in the numeric features.

Instead of deleting observations that were identified as outliers, I used IQR-based capping. This approach preserves the number of observations while reducing the influence of extreme measurements on later statistical analysis. I compared selected features before and after preprocessing and generated visualizations to document the data-quality checks and preprocessing results.

The final project contains the raw dataset, cleaned dataset, Python cleaning script, Jupyter Notebook, visualizations, and a detailed DOCX report. The report explains the methodology, preprocessing decisions, challenges, limitations, and potential effects of cleaning on future exploratory analysis or machine-learning tasks. The work is designed to be reproducible and can be uploaded to GitHub as the technical project repository required for the internship submission.
